# UniHub

## Sobre o Projeto

O **UniHub** é uma plataforma desenvolvida com o objetivo de facilitar a busca e o acesso a informações sobre universidades e cursos de ensino superior no Brasil.

A proposta é centralizar essas informações em um único ambiente, permitindo que o usuário encontre universidades de forma mais rápida e organizada por meio de filtros, mapa interativo e sistema de favoritos.

---

## Objetivo

O principal objetivo do projeto é criar uma plataforma que facilite a pesquisa de instituições de ensino superior, permitindo que o usuário consulte informações sobre universidades, cidades, estados e cursos oferecidos.

O projeto busca tornar o processo de pesquisa mais simples, intuitivo e organizado.

---

## Funcionalidades Planejadas

Durante o planejamento do projeto, foram definidas as seguintes funcionalidades:

- 🗺️ Mapa interativo do Brasil;
- 📍 Localização das universidades no mapa;
- 🔎 Filtro de universidades;
- ⭐ Sistema de favoritos;
- 👤 Cadastro e login de usuários;
- 🏫 Página com informações das universidades;
- 🎓 Informações sobre cursos oferecidos;

---

## Funcionalidades Desenvolvidas

Ao longo do desenvolvimento, foram implementadas as principais estruturas e funcionalidades planejadas para o projeto:

- Configuração do sistema de rotas;
- Implementação do sistema de filtros;

Algumas funcionalidades ainda podem receber melhorias e aperfeiçoamentos em versões futuras.

- Configuração das rotas;

- Sincronização do trabalho realizado pelos integrantes.

Essas dificuldades contribuíram para o aprendizado do grupo e foram solucionadas ou contornadas durante o desenvolvimento do projeto.

### Nota do Grupo

**8,5 / 10**

### Justificativa

O grupo atribui ao projeto a nota **8,5/10**, considerando que grande parte dos objetivos inicialmente propostos foi alcançada.

O UniHub apresenta uma proposta clara e possui uma estrutura funcional, incluindo a interface da aplicação, sistema de filtros, mapa, favoritos e banco de dados.

A nota não foi máxima porque algumas funcionalidades ainda podem ser aprimoradas, principalmente em relação à integração entre os diferentes componentes do sistema, quantidade de informações disponíveis, refinamento da interface e melhorias na experiência do usuário.

Mesmo com essas limitações, o projeto representa uma evolução significativa do grupo e demonstra a aplicação dos conhecimentos adquiridos durante o desenvolvimento.
